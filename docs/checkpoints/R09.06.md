# R09.06 / UX — предложение навигации после Build 12
Статус: proposed, не утверждён и не реализован; 2026-11-25. Связь R09.01/R09.06/R09.07, R04.04. Владелец отметил неудобство навигации при функционально успешном M08. Причина неудобства самим владельцем не конкретизирована. Анализ кода beeac785: AlphaScreen хранит отдельные флаги tabs; ObligationPreview — editor/detail локально, при смене вкладки может потерять состояние; общая прокрутка, действия редактирования/удаления после истории, Home Add только при пустом списке. Предложение для согласования, не факт пользовательской ошибки.
- Главная: раздельные итоги валют, известные даты платежей без выдуманного графика, быстрые действия «Добавить кредит» / «Записать платёж» с выбором обязательства, короткий список. Не смешивать банковский остаток и журнал.
- Нижние вкладки Главная / Кредиты (название предложено, сохранить все типы) / Настройки. Календарь и аналитика только после реализации. Предсказуемый Back, сохранение позиции списка и состояния вкладки, уход из несохранённой формы с подтверждением; не прерывать запись.
- Карточка: заголовок с Back/меню, остаток по данным банка, сумма и дата ближайшего известного платежа, основная кнопка записи, вкладки Обзор/Платежи/Условия. Редактирование и подтверждённое удаление в меню; архивация после реализации. История коррекций после R04.04, без скрытого удаления. Единообразная навигация, RU/EN, светлая/тёмная/системная темы, доступность, размеры целей >=48dp.
- Проверки: Home→новая запись; Home→выбор обязательства→платёж; список→карточка→редактор→назад, возврат в список на прежнюю позицию; смена вкладок и возврат; клавиатура, отмена/несохранённый ввод, busy/error, reboot/recreate, TalkBack/large font, API26/36, регрессия CRUD и платежей. Не менять схему, ключи, финансовые правила или подпись. Точные решения согласовать прежде реализации. Откат UI через Git revert; текущий Build 12 ручная приёмка продолжается. 17/68, критерии без изменений.
