# Build 12 — полный ручной чек-лист

## Важные условия до начала
Только вымышленные записи. Сборка предназначена для диагностики, а не реальных финансовых данных. Не устанавливать временный debug APK поверх рабочего приложения; не удалять приложение, не очищать данные, не менять ключ/подпись и не отключать защиту Android. Для обновления требуется отдельно допущенный подписанный APK и проверенный план восстановления. Если на телефоне есть реальные финансовые данные — не обновлять в рамках этого теста, использовать отдельный тестовый телефон. Если сборка/подпись/допуск ещё не подтверждены — M03 и дальнейшая проверка именно этой сборки BLOCKED. При потере данных, сбое миграции или ошибке ключа остановиться, ничего не записывать, сообщить точный текст. Не проводить намеренное заполнение диска, удаление ключей или повреждение рабочей базы.

Результаты: PASS / FAIL / SKIP (не проверено) / BLOCKED. Для FAIL укажите ожидаемое и фактическое поведение. Для каждого телефона отдельный отчёт. Даты ISO; «сегодня» — дата в банковской зоне, используйте текущую дату устройства при корректных настройках времени. Суммы примеров не являются финансовыми рекомендациями. UI отмены/коррекции ещё отсутствует; PAY03/PAY05 проверяют репозиторий, не интерфейс. Календарь/уведомления/стратегии/backup не реализованы в этом срезе — не искать их и не засчитывать.

## Автоматический отчёт
Настройки → О приложении → Автотестирование → Запустить проверки → Копировать отчёт. 26 сценариев, включая 1000 синтетических распределений внутри FIN10. Отчёт содержит модель/API/ABI/page size, версию, ID/PASS/FAIL, длительность, класс ошибки, пропущенные проверки. Не содержит названий, балансов, идентификаторов, ключей реальных записей. Страница 16 KiB в отчёте — диагностика, не доказательство полной совместимости. После прерывания процесса повторить запуск. Не считать DDL rollback доказательством реального обновления APK или полного recovery.
