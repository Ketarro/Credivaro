# Build 11 — самопроверка, этап 1
Статус: реализация, CI ожидается; платежи и миграция R03.06/R04.01 следующий этап. Только синтетические данные. Версия 0.1.0-alpha, Build 11.

## На телефоне
1. После подтверждения CI установить подписанный APK поверх Build 10, не удалять приложение.
2. Включить запись экрана, не показывать реальные обязательства и личные уведомления.
3. Настройки → О приложении → Автотестирование → Запустить проверки. Не закрывать процесс до завершения; можно выйти из окна и вернуться, состояние сохраняется до завершения процесса.
4. Дождаться результата, показать итог и при необходимости прокрутить список. Кнопка «Копировать отчёт» позволяет отправить обычный текст с ID, PASS/FAIL, длительностью, API и версией, без записей/ключей.
5. Отдельно проверить обновление и сохранность записей, RU/EN/системный язык, темы, клавиатуру, визуальные переходы, reboot и запуск, лицензионное пояснение. Самопроверка их не засчитывает. Для визуального анализа можно прислать доступную запись или ключевые скриншоты.

## Автоматические случаи
FIN01–04: суммы, ноль/неизвестный, даты, валюты.
DB01–06: типы и reopen, ревизии/rollback, удаление, неверная запись, шифрование/неверный ключ, повреждение тестового key envelope.
Каждый DB-тест использует отдельное имя selfcheck-UUID.db, отдельный Keystore alias и cleanup по точному имени. Только DEBUG, не читает рабочие обязательства. Сбой/прерывание не считается PASS; тестовые остатки после принудительного завершения не затрагивают рабочую БД. Не заменяет миграционные/безопасностные тесты CI.
