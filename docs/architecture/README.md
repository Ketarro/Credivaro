# Архитектура Credivaro v1.0

Статус: проект решений для обсуждения; код пока не реализован. Зависит от продуктовых требований PR #2 и базовой документации PR #1, но файлы этого PR независимы от их слияния.

- [SYSTEM-DESIGN-v1.ru.md](SYSTEM-DESIGN-v1.ru.md) — модули, зависимости, UI, транзакции и тестирование.
- [DATA-MODEL-v1.ru.md](DATA-MODEL-v1.ru.md) — логическая модель данных и инварианты.
- [EVENT-ENGINE-v1.ru.md](EVENT-ENGINE-v1.ru.md) — правила календаря, пересчёт и уведомления.
- [SECURITY-v1.ru.md](SECURITY-v1.ru.md) — модель угроз, проект защиты, критерии готовности.
- [DECISIONS-v1.ru.md](DECISIONS-v1.ru.md) — решения, этапы реализации и открытые вопросы.

Это логическая архитектура, не миграция SQL и не готовые Gradle-модули. Версии SDK и библиотек выбираются и проверяются при создании сборки.
