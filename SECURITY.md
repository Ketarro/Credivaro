# Security policy

Credivaro is in the planning stage; there are no supported application releases yet.

For potential vulnerabilities, use GitHub's private vulnerability reporting feature if enabled. Otherwise contact the maintainer privately via a contact method they publish. Do not post exploit details or financial data in public issues.

Include affected version or commit, reproducible steps using synthetic data, impact and possible mitigation. Never send real bank statements, card numbers, credentials or encryption keys. Do not test against other users or systems without authorization.

Security priorities: local-first storage, data minimization, explicit opt-in for data transfer, safe backup/restore, protected keys, safe notifications and dependency review. These are design requirements, not implemented guarantees.
