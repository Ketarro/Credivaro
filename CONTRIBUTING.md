# Contributing to Credivaro

Russian and English contributions are welcome. Start with an issue describing the problem, scope and acceptance criteria. For substantial changes, discuss the design before coding.

1. Fork or create a focused branch from main.
2. Make small, documented changes with tests where relevant.
3. Run available checks and state which were run in the pull request.
4. Link the issue, explain calculation assumptions, and include synthetic screenshots if relevant.
5. Wait for review before merging.

Do not commit real financial records, credentials, signing keys or personal data. Use fabricated fixtures. Respect the Apache 2.0 license, third-party licenses and the project's branding. No APK or build instructions exist yet; setup guidance will follow initialization. Be respectful and constructive.
