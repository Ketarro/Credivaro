# Каталог дополнительных ролей
 10 базовых + 39 дополнительных = 49 ролей, не обязательных отдельных файлов. Критерии ниже — правила адаптации, а не сведения о конкретном проекте.

## Правила выбора
- INIT: обследуй текущие источники и оцени каждую из 39 ролей. Сначала используй существующий источник, затем подходящий раздел, и только при реальной необходимости создай самостоятельный документ. При отсутствии потребности укажи причину. Не создавай пустые файлы ради количества.
- Запиши решение в `project.json` → `optional_sources`: ключ — точное имя из каталога, значение — объект источника по CONFIG_GUIDE.md. Для общего файла укажи конкретный раздел в `note`. Для внешнего источника укажи ID/URL и границы проверяемости. Для неприменимого — обоснование. Неизвестное оставляй unresolved до проверки; не подменяй неизвестность неприменимостью.
- Источники не должны дублировать друг друга: ROADMAP/трекер владеет задачами, DECISIONS — решениями, HANDOFF/checkpoint — текущим состоянием, CHANGELOG — фактическими изменениями, TEST_MATRIX — проверками. Производные сводки ссылаются на первичные источники. Код, схемы, манифесты, дизайн-токены и CI являются первичными для своих машинных фактов.
- В каждом режиме загружай только применимые дополнительные источники, включая требования, безопасность и критерии приёмки, если они затрагиваются. При изменении проекта пересмотри затронутые роли и обнови карту. Не считай наличие файла доказательством качества или актуальности.
