# Режимы работы

Общий контракт применяется во всех режимах. Пути источников — в project.json; отсутствующее не выдумывать.

| Режим | Читать дополнительно | Результат |
|---|---|---|
| INIT | существующие инструкции, README, дерево, CI | карта ролей, адаптация, реальные проверки |
| PROJECT_ZERO | PROJECT_ZERO.md, project-zero.json, применимые источники | адаптивное интервью, согласованный план, проверка готовности |
| DEVELOP | roadmap, architecture, tests, done | реализация, тесты, обновления источников |
| AUDIT | architecture, tests, done | находки с доказательствами и приоритетом; без изменений по умолчанию |
| REFACTOR | architecture, decisions, tests | изменения с проверкой сохранения поведения |
| UX | architecture, tests, требования дизайна | изменения с проверкой сценариев и адаптива |
| DOCS | все затронутые источники и код | актуальная документация без догадок |
| PLAN | roadmap, decisions, architecture | задачи и критерии; не реализация |
| REVIEW | diff, tests, done | замечания, риски, решение о готовности |
| TEST | tests, done, требования | реальные результаты и ограничения |
| RELEASE | changelog, tests, done, правила релиза | проверяемая сборка/релиз в пределах разрешений |
| RECOVER | архитектура, план отката, Git | восстановление после проверки полномочий |
| RESUME | handoff, checkpoint, Git/diff при наличии | проверенный следующий шаг без повтора |

Если пользователь просит комбинированный режим, явно укажи применимые правила и проверки. План и аудит не дают автоматического разрешения на исправления. При конфликте режима и явного запроса соблюдай ограничение на изменение данных и полномочия.
