# Credivaro — Кредиваро

![Signal Frame](branding/logos/symbol-light.svg)

**Твои кредиты. Твой план. Твой контроль.**

[English](README.md) · [Дорожная карта](ROADMAP.md) · [Концепция](docs/PROJECT.md)

Открытое Android-приложение для учёта кредитов, кредитных карт, рассрочек и управления погашением задолженности.

## Возможности, которые планируется реализовать
- Единый список обязательств с индивидуальными банковскими условиями.
- Учёт платежей и подтверждённых остатков.
- Финансовый календарь и гибкие уведомления о платежах, выписках, льготных периодах и обновлениях лимитов.
- Прогноз расходов, статистика и сравнение стратегий погашения.
- Автономная работа, без обязательной регистрации; защита локальных данных.

## Статус
Проектирование. Первая планируемая версия приложения — **v0.1.0-alpha**. APK пока нет. Дорабатываем приложение итерациями в статусе предварительной версии до явного решения владельца проекта о готовности к стабильному релизу. См. [правила версионирования](docs/VERSIONING.md). Приложение не выдаёт кредиты и не проводит платежи. Расчётные прогнозы необходимо сверять с данными банка.

Планируемый стек: Kotlin, Jetpack Compose, Material 3, Room. Лицензия: [Apache 2.0](LICENSE).
